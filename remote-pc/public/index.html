Home PC Remote

1. Gép felébresztése

Wake-on-LAN csomag küldése a Pi-n keresztül a Windows gépnek.

Még nem történt semmi.

2. VS Code elindítása

VS Code elindítása mappa megnyitása nélkül.

Még nem történt semmi.

3. Új projekt mappa létrehozása

A Windows agent konfigurációjában beállított projects-root alá kerül.

Még nem történt semmi.

4. Mappa megnyitása VS Code-ban

A fent kiválasztott mappa megnyitása VS Code-ban.

Még nem történt semmi.

5. Mappa megbízhatóvá tétele

A megnyitás mindig --disable-workspace-trust-tal fut, tehát ez a legtöbbször felesleges — de ha a trust-dialógus mégis megjelenne, ez a gomb újraküldi a parancsot a kiválasztott mappára.

Még nem történt semmi.

6. Remote Control csatlakoztatása

Elindítja a claude-ot a kiválasztott mappában, majd elküldi neki a /remote-control parancsot. Utána a claude.ai/code appból tudsz rácsatlakozni.

Még nem történt semmi.

(még nincs kimenet)

7. Számítógép leállítása

Leállítja a Windows gépet. Megerősítést kér, véletlen koppintás nem indítja el.

Még nem történt semmi.
